Ajan Ahmed, PhD

Electrical & Computer Engineering · Voice Biometrics & Trustworthy AI

Dr. Ahmed holds a Ph.D. in Electrical and Computer Engineering from Clarkson University, an M.Eng. in Electrical and Computer Engineering from Southern Illinois University Carbondale, and a B.Sc. in Electrical and Electronic Engineering from North South University, Bangladesh. His research makes voice biometrics reliable in the real world — speaker recognition, biometric quality assessment and standardization, deepfake audio, and trustworthy AI. Based in Edmonton, Alberta.

Machine Learning Engineer — ImransLab, Dhaka, Bangladesh

  • Dates: April 2018 – July 2019 (surgical-item detection, sepsis detection); August 2020 – February 2021 (COVID-19 detection GUI)
  • Context: paid client product (not research) delivered through ImransLab: a GUI application for doctors that detects COVID-19 from lung images (chest X-ray and CT) with machine-learning models, built by the teacher (Ajan) with a student team.
  • Duties:
    • Gathered requirements with the client, agreed on scope, deliverables, and timelines, and gave regular progress updates
    • Worked in a cross-functional team with the client's product manager, engineers, and doctors to turn requirements into product features
    • Collected and curated public medical-imaging datasets (COVID-19 Radiography Database, COVIDx, SARS-CoV-2 CT-scan data) and organized labels for COVID-19, pneumonia, and normal cases
    • Built the preprocessing pipeline: resizing, intensity normalization, contrast enhancement (CLAHE), data augmentation, and handling of DICOM and PNG / JPEG files
    • Trained and compared convolutional neural networks with transfer learning (VGG16, ResNet50, DenseNet121, InceptionV3, EfficientNet) in TensorFlow / Keras and PyTorch
    • Handled class imbalance with class weights and oversampling; tuned hyperparameters with k-fold cross-validation
    • Evaluated models with accuracy, sensitivity, specificity, precision, F1, ROC-AUC, and confusion matrices, keeping patient-level splits to avoid data leakage
    • Added explainability with Grad-CAM heatmaps so clinicians could see which lung regions drove each prediction
    • Experimented with lung segmentation (U-Net) before classification
    • Designed and built a GUI application for doctors: upload chest X-ray / CT images, get a COVID-19 / pneumonia / normal prediction with confidence scores and Grad-CAM heatmaps, and export a patient report
    • Gathered feedback from doctors on usability and workflow, and improved the interface over several release iterations
    • Built the desktop GUI (PyQt / Tkinter) and a web version with a REST API (Flask), packaged the app for installation on clinic computers (PyInstaller, Docker), and handled version releases
    • Wrote a user manual, trained doctors and staff to use the app, and delivered code, trained models, and documentation to the client
    • Protected patient data: removed identifying DICOM metadata, stored records locally with access control, and followed the client's privacy requirements
    • Tested the app end to end (unit tests with pytest, test images, and doctor acceptance testing) and fixed bugs before each release
    • Made inference fast on ordinary clinic computers by exporting models to ONNX / TensorFlow Lite and running on CPU
    • Hosted the web version on a cloud server (AWS EC2 / Heroku) for remote access, with logging to track usage and errors, and monitored model performance after release
    • Versioned models and datasets, kept a changelog, and maintained the app after hand-over with updates and support
    • Led and mentored the student team: split tasks, reviewed code, and managed the project with Git / GitHub
  • Tech stack: Python, TensorFlow / Keras, PyTorch, torchvision, OpenCV, scikit-image, pydicom, scikit-learn, NumPy, pandas, Matplotlib, Grad-CAM; PyQt / Tkinter (desktop GUI), Flask, HTML / CSS / JavaScript (web GUI), REST API, SQLite (patient records); PyInstaller, Docker; ONNX / ONNX Runtime, TensorFlow Lite; pytest; AWS EC2 / Heroku; Git / GitHub; Google Colab / Kaggle GPUs
  • Highlights:
    • Delivered a healthcare AI product: a GUI application that lets doctors detect COVID-19 from chest X-ray and CT images with deep-learning models, from requirements to release.
    • Built image preprocessing and augmentation pipelines and trained transfer-learning CNNs (ResNet50, DenseNet121, EfficientNet) in TensorFlow / Keras and PyTorch.
    • Evaluated models with sensitivity, specificity, and ROC-AUC using patient-level splits, and added Grad-CAM explanations for clinicians.
    • Built desktop (PyQt) and web (Flask, REST API) interfaces with Grad-CAM heatmaps and patient reports, improved them from doctors' feedback, and trained clinical users.
    • Led a development team through development, testing, and release.
  • Earlier ImransLab projects (April 2018 – July 2019; tools limited to what existed then):
    • Retained surgical item detection (gauze / sponge left inside the body) from ultrasound, CT, and X-ray (AI for surgical-safety review of post-operative scans; retained gauze is also called gossypiboma)
      • Framed the clinical problem with surgeons and radiologists, and defined annotation criteria and quality standards for retained gauze, sponges, and look-alike structures
      • Collected and curated de-identified ultrasound videos and frames, CT volumes, and X-rays (DICOM), and organized labelling with radiologists in 3D Slicer, ITK-SNAP, and LabelImg, with inter-annotator agreement checks and adjudication
      • Built preprocessing for each modality: CT windowing and resampling to isotropic voxels, intensity normalization, ultrasound speckle reduction and cropping, and 2D / 3D patch extraction
      • For ultrasound specifically: worked from B-mode frames and cine loops, handled speckle noise (median, anisotropic diffusion, and wavelet filtering), depth-dependent gain and shadowing artifacts, probe and machine variation, and normalized images across devices before training; segmented targets across cine-loop frames with temporal smoothing and optical-flow-guided mask propagation (video segmentation)
      • Trained and compared segmentation models (U-Net, attention U-Net, 3D U-Net, V-Net, FCN) and detection models (YOLOv3, Faster R-CNN, RetinaNet, Mask R-CNN) in TensorFlow / Keras and PyTorch
      • Used transfer learning from ImageNet and self-supervised pre-training on unlabelled scans (convolutional autoencoders and pretext tasks such as rotation prediction and context restoration) to cope with few labelled cases
      • Handled class imbalance and hard negatives (surgical clips, drains, bowel gas, calcifications) with focal / Dice loss, hard-negative mining, and heavy augmentation
      • Evaluated with Dice, IoU, sensitivity, specificity, mAP, and FROC with patient-level splits, analyzed failure modes case by case with clinicians, and added Grad-CAM and saliency maps for review
      • Compressed the models (knowledge distillation, pruning, quantization) and served them through a review tool that flags suspicious regions for the radiologist
      • Built the processing and visualization path for the review tool: batch inference over scan series, overlays of predicted masks and boxes, and per-case reports; documented models, training settings, and dataset procedures for engineers
      • Added geometric analysis of each 3D segmentation: object volume, centroid, and extent from the voxel spacing, surface meshes with marching cubes (scikit-image, VTK) for 3D review, and surface-distance checks of mask quality (Hausdorff distance, average surface distance) alongside Dice
    • Sepsis (septicemia) early detection from clinical data
      • Built early-warning models that predict sepsis hours before onset from vital signs, laboratory results (e.g. lactate, white blood cell count, creatinine), demographics, and clinical notes in hospital records
      • Prepared longitudinal patient time series: irregular sampling, missing-value imputation, forward filling, time windows, and patient-level train / test splits to avoid leakage (MIMIC-III)
      • Defined sepsis cohorts and labels from billing diagnosis and procedure codes (ICD-9, Angus criteria; claims-style admission records) together with clinical criteria (Sepsis-3); used the admission and health-insurance fields (payer type: Medicare, Medicaid, private, self-pay) to describe cohorts and check model performance across payer groups
      • Trained and compared gradient boosting (XGBoost, LightGBM), logistic regression, LSTM / GRU, and 1D convolutional models, with SHAP explanations of the main risk drivers
      • Fused structured data (vitals, labs) with clinical-note text features (TF-IDF, word2vec / fastText embeddings) and chest X-ray CNN features where available (multimodal fusion)
      • Built the clinical-note NLP pipeline: text cleaning, sentence splitting, abbreviation expansion, negation handling (NegEx-style rules), medical concept extraction (MetaMap / cTAKES and spaCy rules), and TF-IDF and word2vec features for symptom and infection mentions
      • Evaluated with AUROC, AUPRC, sensitivity at fixed alert rates, calibration, and lead time before onset, and reviewed false alarms with clinicians
      • Wrote model documentation and validation reports, and presented results to clinical partners
      • Adjusted alert thresholds with clinicians to balance sensitivity against false-alarm burden
