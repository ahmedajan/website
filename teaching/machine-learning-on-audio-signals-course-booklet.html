B1. Machine Learning on Audio Signals: Course Booklet

  • Authors: M. H. Imtiaz, A. Ahmed, and Y. Sukhdeve
  • For: EE 502 Machine Learning on Biomedical Signals, Wallace H. Coulter School of Engineering and Applied Sciences, Clarkson University, Fall 2025 / 2026
  • Format: ~120-page self-contained course booklet (9 chapters), grown from EE 502 lecture notes; every major concept comes with a Python script (librosa, NumPy, scikit-learn), exercises, and Jupyter notebooks. Modular, so it can be used for a 10-week special topic, a semester survey, or a short professional workshop. Institutional course material (not commercially published).
  • Chapters:
    1. Introduction to Speech Signals: analog vs. digital, amplitude / frequency / phase, time vs. frequency domain, Nyquist–Shannon sampling, quantization and bit depth, Fourier transform, STFT, mel spectrograms, practical audio systems
    2. Speech Preprocessing and Feature Extraction: resampling, noise reduction, silence trimming, normalization, framing and windowing, spectrograms, ZCR, energy and spectral features, MFCCs, log-mel and pitch, formants, feature scaling, feature comparison and fusion
    3. Machine Learning on Audio Signals, a Summary: supervised / unsupervised learning, evaluation metrics, batch vs. online, instance- vs. model-based learning, challenges of speech ML, validation and hyperparameter tuning
    4. Audio Classification Using MFCCs and Decision Tree Models: decision trees and Random Forest, embedded-system constraints, denoising, feature selection, effect of MFCC dimensionality, confusion matrices
    5. Keyword Detection Using Random Forest
    6. SVM-Based Speaker Classification: ANOVA, k-fold cross-validation, chi-squared tests
    7. Speech Emotion Recognition Using MFCC and Machine Learning
    8. Voice-Based Gender Identification: data harmonization, EDA, dimensionality analysis, hyperparameter search, model compression and deployment
    9. Deepfake Audio Detection via MFCC Features Using Machine Learning: Fake-or-Real (FoR) variants, noise augmentation, model comparison
  • My contribution: wrote the entire booklet (all 9 chapters, code, and exercises); co-authors Dr. Imtiaz and Y. Sukhdeve reviewed and cross-checked it
  • Highlights:
    • Wrote a ~120-page, 9-chapter course booklet, Machine Learning on Audio Signals, for Clarkson's EE 502 as lead author (all chapters, code, and exercises; reviewed by co-authors), covering speech signal fundamentals, feature extraction, and applied ML (keyword detection, speaker classification, emotion recognition, gender identification, deepfake detection).
    • Paired every chapter with runnable Python code (librosa, NumPy, scikit-learn), exercises, and Jupyter notebooks, turning lecture notes into a modular resource usable for a semester course, a special topic, or a professional workshop.
