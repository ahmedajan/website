B2. Embedded Machine Learning: Using the Silicon Labs EFR32XG24 BLE Microcontroller (Course Booklet)

  • Authors: M. H. Imtiaz, A. Storey, A. Ahmed, and A. Kia
  • For: EE 513 Intelligent System Design, Wallace H. Coulter School of Engineering and Applied Sciences, Clarkson University, Spring 2026
  • Format: ~150-page self-contained course booklet (11 chapters), grown from EE 513 lecture notes; every concept comes with code tested on the EFR32XG24 development kit, plus exercises and lab projects. Modular, for a 10-week special topic, a semester survey, or a professional workshop. Institutional course material (not commercially published).
  • Chapters:
    1. Introduction to Embedded Machine Learning: applications, the EFR32MG24 microcontroller
    2. The Art and Science of Machine Learning: learning paradigms, uncertainty, regularization, building learning systems, ethics and governance (fairness, transparency, safety)
    3. Model Preparation and Conversion for Microcontroller Deployment: data collection, model design, TensorFlow Lite conversion, model optimization and quantization
    4. The "Hello World" of TinyML: a sine-wave model in Google Colab, quantization, conversion to C, deployment with Simplicity Studio and the Gecko SDK, LEDs / LCD / buttons, power optimization, profiling
    5. Building a TinyML Application: Gecko SDK workflow, PWM output, debugging, memory / power / timing optimization, custom TinyML components
    6. Handwriting Digit Recognition: on-device CNN, quantization effects, resource use, comparison with cloud approaches
    7. IMU-Based Gesture Recognition: CNN, post-training quantization, sensor fusion, motion detection
    8. Real-Time Posture Detection Using Neural Networks: data acquisition, firmware architecture, wireless communication
    9. Real-Time Gesture and Anomaly Detection: impulse design, spectral features, anomaly detection (Edge Impulse workflow), deployment on EFR32MG24
    10. Real-Time Flame Detection Using a Thermal Infrared Sensor: data-streaming firmware, Python data collection, training, on-device inference
    11. Keyword Spotting: mel-spectrogram dataset creation, CNN, optimization and conversion, deployment on EFR32xG24
  • My contribution: wrote the entire booklet text (all 11 chapters); A. Storey developed the code examples; Dr. Imtiaz and A. Kia reviewed and cross-checked it
  • Highlights:
    • Wrote a ~150-page, 11-chapter course booklet, Embedded Machine Learning, for Clarkson's EE 513 Intelligent System Design as lead writer (all chapter text; code by a co-author), teaching TinyML deployment on the Silicon Labs EFR32XG24 BLE microcontroller.
    • Structured hands-on, hardware-tested labs covering model quantization and TensorFlow Lite conversion, and on-device applications for keyword spotting, gesture and posture recognition, anomaly detection, handwriting recognition, and thermal flame detection.
